# UX Evaluation

## Когда использовать

Только при анализе интерфейса, usability, flow или прототипа.

## Эвристики Нильсена

1. Видимость состояния системы
2. Соответствие реальному миру
3. Контроль и свобода пользователя
4. Консистентность и стандарты
5. Предотвращение ошибок
6. Распознавание вместо вспоминания
7. Гибкость и эффективность
8. Минимализм
9. Помощь в распознавании и исправлении ошибок
10. Помощь и документация

## Правила

- Не перечислять эвристики без анализа.
- Каждая проблема должна быть привязана к конкретному месту интерфейса.
- Для каждой проблемы: эвристика → проблема → риск → рекомендация.
