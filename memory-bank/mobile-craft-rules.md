# Mobile Craft Rules

## Назначение

Дополнение к mobile platform guidelines для визуального качества мобильных экранов.

## Правила

- Интерфейс должен ощущаться как приложение, а не сайт в телефоне.
- Учитывать safe areas и системную навигацию.
- Не использовать tiny text.
- Touch targets не должны быть слишком маленькими.
- Не перегружать экран floating cards.
- Не делать fake fintech dashboard spam.
- Не клонировать один и тот же экран с разным текстом.
- Bottom sheets, tabs, nav bars должны быть platform-aware.

## Mobile anti-slop

- Слишком много glassmorphism.
- Слишком много градиентов.
- Карточки внутри карточек.
- Несистемные radii и spacing.
- Нет состояний ошибки/загрузки/пустого состояния.
- Слишком декоративный motion в продуктовой задаче.
