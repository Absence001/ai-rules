# Figma MCP Workflow

## Когда использовать

Только если пользователь явно хочет работу в Figma или задача требует Figma MCP.

## Порядок

1. Проверить подключение MCP.
2. Проверить `figma.config.json`.
3. Провести аудит текущего Figma-файла.
4. Сначала Foundation / Tokens.
5. Затем Components.
6. Затем Screens.
7. Затем Prototype connections.

## Правила

- Не перетирать существующие компоненты без подтверждения.
- Если компонент уже есть — переиспользовать или обновить.
- Все системные значения через Variables/Styles.
- Flow собирается из компонентов, не raw-слоев.
- Если MCP недоступен — записать план и продолжить текстом/кодом.
