# Brief Expander

## Когда использовать

Если запрос расплывчатый, 1–3 строки, без нормального ТЗ.

## Порядок

1. Не дополняй запрос сам.
2. Задай 4–6 вопросов одним раундом.
3. Приоритет вопросов:
   - аудитория и контекст;
   - ограничения;
   - бизнес-цели;
   - fail criteria;
   - метрики успеха.
4. После ответов — короткое резюме 3–5 пунктов.
5. Если контекст всё ещё слабый — следующий раунд.
6. Когда достаточно — запиши `artifacts/brief.md`.

## Если пользователь отвечает “не знаю”

Не выдумывай. Пометь как открытый вопрос.
