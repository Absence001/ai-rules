# Code Diagnostics

## Когда использовать

Баги, код, конфиги, логи, зависимости, запуск проекта.

## Обязательный формат ответа

- ПРОБЛЕМА: …
- ГДЕ ИМЕННО: …
- КАК БУДЕМ РЕШАТЬ (план): …
- ЧТО ИЗМЕНИТСЯ ПОСЛЕ: …
- КАК ПРОТЕСТИРОВАТЬ ПОСЛЕ РЕШЕНИЯ: …
- УВЕРЕННОСТЬ: X%
- ВОПРОС: Могу ли я начать исправление?

## Правила

- Сначала найти проблему, потом предлагать правки.
- Проверить гипотезу 3 раза: код, конфиг, логи/симптомы.
- Не менять код без разрешения.
- Изменения минимальные.
- После правок: что/почему/какие файлы/как проверить.
