# Artifact Contracts

## Общие правила

- Каждый артефакт должен быть коротким, структурированным и пригодным для следующего этапа.
- Не дублировать весь предыдущий артефакт — ссылаться на ключевые решения.
- Открытые вопросы помечать явно.
