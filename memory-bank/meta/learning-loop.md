# Learning Loop

Как система учится на собственных сессиях. Модель заимствована из
`continuous-learning-v2` проекта everything-claude-code (ECC), переработана под эту
систему и под нативную Windows.

## Зачем

До этого правила менялись только вручную: пользователь замечал дрейф и правил файл.
Урок каждой сессии терялся, одни и те же поправки вносились заново (видно по git-истории:
серия коммитов `fix drift`). Цикл обучения закрывает эту дыру.

## Схема

```
сессия (Codex или Claude)
      │
      │ PostToolUse + UserPromptSubmit — детерминированные хуки
      ▼
observations.jsonl        промпты и цели инструментов, по проекту
      │
      │ скилл distill — ТОЛЬКО по просьбе пользователя
      ▼
инстинкты .md             триггер → действие, confidence 0.3–0.9, domain, scope
      │
      ├─ SessionStart инжектит те, у кого confidence >= 0.7
      │
      │ promote: >= 0.9 и встречен в 2+ проектах
      ▼
правило в memory-bank/    ← перенос делает ПОЛЬЗОВАТЕЛЬ, после ревью
      │
      ▼
sync-rules.bat → оба рантайма
```

Последний шаг — то, чего нет у ECC. У них инстинкты навсегда остаются в data-каталоге.
Здесь есть репозиторий правил, поэтому созревший инстинкт может стать **правилом системы**
и разойтись на оба рантайма. Это и делает репозиторий самообучающимся.

## Почему хуки, а не скилл

> «Skills are probabilistic — they fire ~50-80% of the time based on the model's judgment.»
> — ECC, continuous-learning-v2

Хук срабатывает **всегда**. Наблюдение, которое зависит от решения модели, —
это не наблюдение, а выборка с неизвестным смещением.

## Почему нет фонового агента

У ECC анализом занимается фоновый observer на Haiku раз в 5 минут. На нативной Windows
он не выживает: процесс убивается при выходе породившего хука, когда закрывается Job Object
(их же документация, issue #2489). Плюс их реализация требует Python, а `python3` на этой
машине — WindowsApps-stub, который печатает `Python` и выходит.

Поэтому: всё на Node, дистилляция — **ручной шаг** через скилл `distill`.
Это не компромисс, а осознанный выбор: инстинкт меняет поведение всех будущих сессий,
и человек в этом контуре — не узкое место, а защита.

## Уверенность

| Значение | Смысл | Поведение |
|---|---|---|
| 0.3 | Предположение | Предлагается, не навязывается |
| 0.5 | Умеренная | Применяется, когда релевантно |
| **0.7** | Сильная | **Порог инжекта в сессию** |
| 0.9 | Почти точно | Порог промоушена |

Растёт: +0.1 за подтверждение. Падает: −0.3 за опровержение пользователем,
−0.1 за каждые 60 дней молчания (затухание).

Асимметрия намеренная: навязать неверное правило дороже, чем не выучить верное.
Одно опровержение стирает три подтверждения.

## Scope

`project` по умолчанию (хеш от git remote, поэтому переносится между машинами),
`global` — только для правил, очевидно не зависящих от проекта. Разделение не даёт
конвенциям одного проекта протечь в другой — у ECC это называется cross-project contamination.

## Домены

`research` · `ia` · `design-system` · `craft` · `figma` · `frontend` · `pipeline` · `communication`

Под продуктово-дизайнерский пайплайн, а не под код: у ECC домены были
`code-style`, `testing`, `git`, `debugging`.

## Команды

```bash
node scripts/instincts.mjs status            # что выучено
node scripts/instincts.mjs observations 200  # сырые наблюдения
node scripts/instincts.mjs reinforce <id>    # подтвердить
node scripts/instincts.mjs correct <id>      # опровергнуть
node scripts/instincts.mjs promote           # project → global
node scripts/instincts.mjs prune             # убрать выдохшиеся
node scripts/instincts.mjs projects          # известные проекты
```

Разбор наблюдений — скилл `distill`.

## Данные и приватность

Живут **вне репозитория**: `%LOCALAPPDATA%\ai-rules-learning\`
(переопределяется `AI_RULES_LEARNING_DIR`).

- Наблюдения не покидают машину и не версионируются.
- Пишутся промпты и **цели** инструментов (путь к файлу, голова команды) —
  но не содержимое файлов и не вывод инструментов.
- `observations.jsonl` ротируется на 5 МБ.
- Наружу можно отдавать только инстинкты, никогда не наблюдения.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `AI_RULES_LEARNING_DIR` | `%LOCALAPPDATA%\ai-rules-learning` | где лежат данные |
| `AI_RULES_MAX_INSTINCTS` | `8` | сколько инжектить в сессию |
| `AI_RULES_INSTINCT_THRESHOLD` | `0.7` | порог инжекта |

## Отключить

Убрать блок `hooks` из `~/.codex/hooks.json` и `~/.claude/settings.json`.
Накопленные инстинкты останутся на диске и заработают снова при возврате хуков.

## Связь с другими правилами

| Правило | Связь |
|---|---|
| `meta/anti-sycophancy.md` | Коррекция пользователя — главный сигнал для инстинкта. Но уступка при score < 4 **не** повод для записи: закрепится продавленное, а не верное |
| `meta/calibration.md` | Та же шкала уверенности, что у `УВЕРЕННОСТЬ: X%` |
| `meta/operating-principles.md` | Reflexion: разбор провала — естественный материал для инстинкта |
| `templates/project-state.md` | Decision Lineage — решения проекта; инстинкты — поведение агента. Не смешивать |
