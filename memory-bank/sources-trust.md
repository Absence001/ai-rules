# Sources Trust

## Уровни доверия

Высокий:
- прямой бриф;
- фактический интерфейс;
- реальные метрики;
- официальная документация;
- подтвержденные материалы проекта.

Средний:
- отраслевые паттерны;
- конкурентные наблюдения;
- публичные отчеты;
- качественные аналогии.

Низкий:
- предположения;
- непроверенные интерпретации;
- единичные отзывы;
- маркетинговые заявления без подтверждений.

## Правила

- Каждый важный вывод должен иметь основание.
- Цифры — только со ссылкой/источником или пометка “оценка”.
- Если данных мало — остановиться и спросить или отметить гипотезу.
