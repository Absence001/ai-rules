# Flow Design

## Когда использовать

После IA и базовой дизайн-системы.

## Порядок

1. Прочитать `artifacts/ia.md`.
2. Проверить, что есть `artifacts/design-system.md` или разрешение делать быстрый несистемный prototype.
3. Разложить flow на экраны.
4. Для каждого экрана определить:
   - цель;
   - состояние;
   - главный CTA;
   - вторичные действия;
   - компоненты.
5. Записать `artifacts/screens.md`.

## Правила

- Flow закрывает конкретный сценарий, не абстрактную идею.
- Не добавлять экран без задачи.
- Если появляется устойчивый новый паттерн — предложить поднять его в DS.
- Не создавать новые компоненты без объяснения.
