# IA Rules

## Когда использовать

После `artifacts/research.md`, перед дизайном экранов.

## Порядок

1. Прочитай brief, SRGID и research.
2. Выдели главный JTBD.
3. Определи главный сценарий.
4. Определи главный экран.
5. Определи главное действие пользователя.
6. Построй sitemap максимум до 2 уровней.
7. Построй user flow для главного сценария.
8. Запиши `artifacts/ia.md`.

## Правила

- Каждой задаче должен соответствовать минимально необходимый набор экранов.
- Nice-to-have не превращать в экраны.
- Если сценариев несколько — выбрать тот, который закрывает максимум JTBD.
- Не прыгать в UI до IA.
