# Craft Core

## Назначение

Craft-layer отвечает за визуальное качество, ощущение интерфейса и anti-slop. Он не меняет scope, research, IA или бизнес-логику.

## Главный принцип

Вкус = объяснимые решения. Не проси “сделать красиво”; объясняй, что именно улучшает интерфейс и почему.

## Когда использовать

- UI / frontend
- screenshot → code
- redesign
- visual polish
- landing / brand / portfolio
- mobile screens
- prototype quality

Не использовать для research-only, backend-only, config/debug задач.

## Craft commands

- `shape` — спланировать визуальную структуру до кода.
- `critique` — найти слабые места.
- `audit` — проверить по правилам и anti-patterns.
- `polish` — довести уже рабочий UI.
- `distill` — убрать лишнее.
- `typeset` — улучшить типографику.
- `layout` — улучшить сетку, spacing, rhythm.
- `animate` — добавить уместный motion.
- `harden` — проверить состояния, accessibility, responsive.

## Правила

- Сначала определить visual intent.
- Визуальный прием должен работать на задачу, а не украшать ради украшения.
- Polish делать после функциональной готовности.
- Объяснять важные правки форматом: Before → After → Why.
- Motion должен поддерживать feedback, orientation или state change.
