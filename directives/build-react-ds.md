# Directive: build-react-ds

## Цель

Создать React DS в `app/`.

## Шаги

1. Проверить стек и зависимости.
2. Спросить разрешение на установку пакетов.
3. Создать tokens.
4. Создать atoms.
5. Создать molecules.
6. Создать demo page.
7. Запустить проект и проверить.

## Минимальный набор

Atoms: Button, Input, Text, Icon, Badge, Divider.
Molecules: Card, ListItem, FormField, Tabs, Modal/Sheet if needed.
Organisms: только если есть реальный экранный паттерн.
