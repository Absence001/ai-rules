# Directive: build-prototype

## Цель

Собрать кликабельный прототип или web prototype.

## Вход

- `artifacts/ia.md`
- `artifacts/screens.md`

## Шаги

1. Определить стартовый экран.
2. Определить переходы по user flow.
3. Если Figma — связать frames.
4. Если web — настроить routes/interactions.
5. Записать `artifacts/prototype.md`.

## Не делать

- Не создавать сложные conditional flows без запроса.
- Не менять экраны на этапе связки, если это не мелкая правка.
