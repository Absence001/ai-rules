# Directive: create-screens

## Цель

Создать screens на основе IA и DS.

## Вход

- `artifacts/ia.md`
- `artifacts/design-system.md`

## Шаги

1. Определить must screens.
2. Для каждого экрана: цель, состояние, главный CTA, компоненты.
3. Собрать screen в Figma или React в зависимости от задачи.
4. Записать `artifacts/screens.md`.

## Не делать

- Не создавать новые компоненты без причины.
- Не добавлять nice-to-have экраны.
