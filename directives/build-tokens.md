# Directive: build-tokens

## Цель

Собрать tokens как источник правды.

## Структура

- primitive colors
- semantic colors
- typography
- spacing
- radius
- shadow
- motion, если нужно

## Правила

- Semantic tokens должны ссылаться на primitive.
- Никаких hex в компонентах, если есть tokens.
- Не плодить шкалы “на будущее”.
- Если значения placeholder — пометить это.
